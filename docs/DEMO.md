# Demo script (under three minutes)

**0:00–0:20** — Open Studio. “Browser agents can operate applications, but
generated software should not receive unrestricted execution authority.” Show
the visible network-none/resource boundary.

**0:20–0:40** — Show the WebMCP inspector and the focused Studio tools. “The
agent uses product capabilities, not DOM guessing or a generic shell.”

**0:40–1:25** — Ask: “Inspect the project and policy, establish a baseline by
running Workcell and Eval before editing, then diagnose every failure, repair,
rerun, and verify.” The agent inspects state, files, implementation, and policy;
then runs Workcell.
Open the real receipt summary. Run Eval: it fails because blank invoice IDs are
counted as duplicates.

**1:25–2:15** — Agent reads the failure, applies the one-condition patch, and
runs Workcell again. The human watches the file, activity, lifecycle, and diff
update. Run Eval: two duplicate rows, zero failures.

**2:15–2:45** — Verify Workcell and Eval manifests. Show three distinct claims:
execution succeeded, deterministic evaluation passed, evidence verified. Open
policy, receipt, changed files, and manifest summary.

**2:45–2:55** — “WebMCP gives the agent a first-class interface to the app.
Kujo gives its work an execution boundary, verification loop, and evidence
trail humans can inspect.”

Record only the working deployed application. Keep audio clear and the public
YouTube video below three minutes.
