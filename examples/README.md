# Example workflows

The executable examples are the sealed projects in [`templates/`](../templates/):

- `invoice-scanner`: canonical failure → diagnosis → repair → verification loop.
- `log-summarizer`: bounded JSON artifact generation and Eval checks.
- `static-status-page`: declared static artifact generation and content checks.

Use the focused prompts and expected WebMCP selections in
[`docs/WEBMCP.md`](../docs/WEBMCP.md), and the timed submission walkthrough in
[`docs/DEMO.md`](../docs/DEMO.md).
